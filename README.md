## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a8d76c5ac7d6a3e09c3b36b/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **popeye master pro** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a8d76c5ac7d6a3e09c3b36b/releases/latest) and reinstall.
